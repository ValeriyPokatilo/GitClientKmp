# Руководство по использованию CI конфигурации

## Структура конфигурации

Конфигурация разделена на следующие группы:

- **Dev, Stage, Prod** — CI задачи для Android и iOS приложений на dev, stage и prod
  средах.

Сами задачи описаны в [.gitlab-ci.yml](../.gitlab-ci.yml)

Каждая задача запускается при наличии соответствующего тега в репозитории, что позволяет запускать
нужные стадии для различных сред.

## Теги для запуска

- `build/[android|ios]/[dev|stage|prod]/buildNumber` - собрать под
  одну платформу, под конкретную среду. Например `build/android/dev/10`.

Номер билда берем просто следующий, после последнего собранного (вне зависимости от того каким тегом
собирали).

Работа через теги позволяет точно понимать с какого кода собран конкретный билд.
